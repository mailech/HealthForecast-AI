# HealthForecast AI

## Project Overview

HealthForecast AI is a hospital readmission prediction and patient risk
intelligence system developed as part of an Infosys Virtual Internship
project.

The system uses a trained XGBoost machine learning model to estimate the
risk of hospital readmission within 30 days after discharge. It provides
healthcare users with an estimated risk probability and supports
data-driven patient risk assessment.

## Problem Statement

Hospital readmissions within 30 days can increase healthcare costs and
place additional pressure on healthcare resources. Identifying patients
who may be at higher risk of early readmission can help healthcare
professionals prioritize follow-up and care planning.

HealthForecast AI addresses this problem by using patient clinical and
hospitalization information with a trained machine learning model to
estimate 30-day readmission risk.

## Project Objectives

- Develop an AI-based hospital readmission prediction system.
- Estimate the probability of readmission within 30 days.
- Provide a simple healthcare dashboard for prediction and monitoring.
- Store patient and prediction information.
- Provide explainable prediction information where supported.
- Implement secure role-based access for healthcare users.
